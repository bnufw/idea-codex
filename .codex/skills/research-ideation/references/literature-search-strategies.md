# Local Paper Reading Strategies

本项目默认不用在线论文检索。

研究构思阶段的“literature strategy”指的是如何组织本地 `papers/**/*.md`，而不是如何去外部数据库抓论文。

建议顺序：

1. **按问题筛选**：先找和用户 brief 最接近的问题定义
2. **按方法分组**：把相近方法归到同一组
3. **按假设拆分**：记录每类方法依赖的关键前提
4. **按局限对比**：找出反复出现的失败模式
5. **按证据强弱排序**：把信息密度高的笔记放在前面

推荐记录字段：

- problem
- setting
- core mechanism
- assumption
- strongest result in the note
- limitation
- reusable pattern

如果本地笔记不足以支撑 gap 或 novelty 判断，应明确写为“本地证据不足”，而不是自动切到在线检索。
